# BuilderBot（Litematica 設計図の自動建築ボット）

Litematica の設計図（`.litematic`）を読み込み、サバイバルで素材をそろえて、設計図どおりに 1 段ずつ建てるボットです。
素材のそろえ方は 2 通りあります（`BUILD_SUPPLY`）。

- **`stocked`（素材を用意してもらう）**: 素材は手持ちか、建築現場の近くのチェストに用意してある前提で、取り出して建てるだけにします。自分で採掘・精錬・狩りはしません（チェストの原木から板材を作る、のような手元の材料でのクラフトだけはします）。
- **`gather`（自分で集める、既定）**: 足りない素材は自分で掘る・焼く・狩る・作るでそろえます。
移動・採掘・クラフト・精錬などの体の動きは DragonBot（`ai/dragon-bot`）のものをコピーして使っています（DragonBot 側には手を入れていません）。

## できること
- **設計図の読み込み**: 複数の領域、負の向きのサイズ、long をまたいで詰められたブロック状態に対応（`src/building/litematic.js`）。Blender から変換した `sample-monkey.litematic`（4810 ブロック）を読めることをテストで確認しています。
- **素材の調達**（`src/building/acquire.js`）: 足りない素材は、次の中から手間の少ない方法を選んでそろえます。レシピの材料も同じ方法で再帰的にそろえます。
  1. 建築現場の近くのチェスト・樽から取る
  2. 自然にあるブロックを掘る（原木・丸石・土・砂・砂利・粘土・花・鉱石。鉱石が見えなければその高さで横掘り）
  3. 精錬する（ガラス・石・レンガ・テラコッタ・インゴットなど）
  4. 動物から取る（白い羊毛・革・羽根）
  5. クラフトする（板材・ハーフブロック・階段・ドア・松明・色付き羊毛・コンクリートパウダーなど）
  6. コンクリートは、パウダーを水辺に置いて固めてから掘る
- **建築**（`src/building/builder.js`）: 下の段から順に、邪魔な地形をどけ、手持ちに入る分ずつ素材をそろえ、近い順に置きます。
  - **普通のプレイヤーにできる置き方だけ**をします（`src/building/sight.js`）。置く前に、目からクリックする面が見えて（間にブロックが無く、面が自分の方を向いている）、手が届く（4.5 マス）かを当たり判定で確かめ、その点を見て置きます。壁越し・床越しには置きません。掘るときも、見えている面を掘ります。
  - 向きのあるブロック（原木の軸・階段・ドア・かまど・壁の松明・ハーフブロックの上下・看板の向きなど）は、クリックする面と、その点を見たときの向きがバニラの決まりで設計図どおりになる所に立って置きます（例: 北向きの階段は、南側から北を見て置く）。
  - 置けなかったとき・置いたのに無いとき・向きが違ったときは、次のマスへ移る前に**その場で置き直します**（最大 3 回。向き違いは掘って置き直す。掘ると何も落とさないガラスなどは掘らない）。
  - そういう立ち位置が無ければ、**足場**を組みます（**足場ブロック（scaffolding）**があればそれを使い、無ければ土や丸石。足場ブロックはしゃがんで跳びながら積み、片付けは柱のいちばん下を壊して上までまとめて崩します。支えの無い空中の足場は足場ブロックだと落ちるので、そこだけ土を使います）: 見える所に仮の柱を積んで登る、高い所では同じ高さのまま横へ足場を伸ばす（しゃがんで後ろ向きに架ける）、屋根の端など支えが無い所は横か真下に仮のブロックを置く、屋根の真ん中のように近くに柱を立てられない所は建物の外に柱を積んでその高さまで登り、上を歩いて行く。使い終わった柱は掘りながら降り、最後に残った足場も片付けます。足場の位置は `data/job.json` に残るので、再起動しても片付けられます。
  - 壁に付ける松明・上付きハーフブロックのように下からは付けられないものは、付ける先ができるまで後回しにします。砂・砂利などは真下を埋めてから置きます。
  - **落ちない・埋まらない**: 高い所の端ではしゃがんで作業します（しゃがむと端から落ちない）。足元のブロックは掘らず、飛び降りは 3 段まで（4 段からは落下ダメージ）、建築中はダッシュ・飛び越しをしません。床や屋根は、その下に入り込まずに上か外から張ります。目や足の高さに詰まったブロックがあれば（落ちてきた砂利など）、すぐ掘り出します。
  - ドアは、ほかが全部置けてから、なるべく建物の外に立って最後に置きます（経路探索はドアを通れないので、先に置くと建物の中に閉じ込められた）。付けたあとで中に残りが見つかれば、ドアを外して入り、最後に付け直します。それでも閉じ込められたときは、ドアか壁を 1 つ壊して外へ出て、あとで置き直します（壊すと何も落とさないガラスなどは壊しません）。
  - 経路探索には「建てたブロックは壊さない」を教えてあります。素材を用意してもらうモードでは、経路探索にはブロックを置かせず、足場はすべて上の決まりで自分で置きます。
  - 毎回いまの世界の状態を見て、設計図どおりでないマスだけを置くので、中断・再起動・死亡のあとも続きから建てます。
- **反射と安全**: 敵が近づいたら建築を止めて戦い、クリーパーや体力が少ないときは離れます。食事は自動です。
  - 夜は地面に穴を掘ってこもり、朝を待ちます（防具なしで夜に建て続けると、スケルトンに倒されて素材を落としていたため）。昼のうちに羊毛と板材でベッドを作っておき、穴の中で寝て夜を飛ばします。体力が少ないときも穴で休みます。
  - 死んだら、落とした物が消える前に拾いに戻り、建築現場へ戻って続きを建てます。
  - 2 分間まったく動きが無ければ、固まったとみなしてやり直します。
- 手に入らない素材（ダイヤブロックなど）は、ある分だけ置いて先へ進み、最後に足りない物をチャットで伝えます。チェストに入れると、しばらくして続きを建てます。

### 素材を用意してもらうモード（`BUILD_SUPPLY=stocked`）
- 建て始める前に、近くのチェスト・樽・設置したシュルカーボックスを全部開けて、手持ちと合わせて足りない素材をチャットで伝えます（「素材はそろっています」または「素材が足りません: …」）。足りなくても、ある分から建て始めます。
- チェストとの往復を減らすため、取り出すときはこの先の段で使う分もまとめて持っていきます（持ち物は 8 枠空けておく）。持ち物がいっぱいになったら、いま使わない素材はチェストに戻します（捨てません）。
- 建てている途中でチェストに素材を足すと、足りない素材が出たときにチェストを見直して気づきます。最後まで足りなければ、足りない物を伝えて待ち、入れてもらえれば続きを建てます（同じ知らせは 10 分に 1 回だけ）。
- 道具・ベッド・食べ物も、チェストにあればそれを使います（無ければ素手で建てる・穴にこもるだけ・動物を狩る）。地形をたくさんどける建物ではツルハシをすぐ使い潰すので、ツルハシを数本入れておくと速く建ちます。使い潰したときはチェストから次のツルハシを取り、無ければ余り物（どけた丸石など）で作り、それも無理ならチャットで頼みます。
- ベッドがあれば、建築現場のそばに置いてリスポーン地点にします。倒されてもすぐ近くで復活して、落とした素材を拾いに戻れます。夜はそのベッドで寝ます（敵が近くて寝られなければ穴にこもります）。建て終わったらベッドもチェストに戻します。
- 用意された素材は、ほかの物を作る材料にもしません（床に使う板材で、はしごの棒を作らない）。クラフトに使うのは、建築に使う分を超えた余りだけです。
- 用意してもらった素材は、移動の足場・柱上り・穴のふた・松明などには使いません。足場には土や丸石などの安いブロックを使い、チェストに無ければ近くの土を少し掘ります。足場用に土を 1〜2 スタック入れておくと、地面を掘らずに済みます。
- 建て終わったら、余った素材と足場のブロックをチェストに戻します。
- 地下の廃坑・ダンジョンのチェストは使いません（建築現場の高さ付近のチェストだけ）。
- 素材の一覧は `!materials` で確かめられます。建築中なら、残りに足りない素材も答えます。

## 動かし方（Windows）
1. 試験鯖を用意します: `powershell -ExecutionPolicy Bypass -File scripts\setup-test-server.ps1`。作成先は `Documents\ClaudeCode\builder-bot-test`（127.0.0.1:25572、kanetyyy が OP）です。その後 `start.bat` で起動します。
2. `npm install`
3. `.env.example` を `.env` にコピーします。
4. `node --env-file=.env src/main.js`
5. 設計図は `schematics/` に置きます。ゲーム内で（`BUILD_OWNERS` のプレイヤーが）チャットで指示します。
   - `!build 名前` … 自分の足元を設計図の最小角（北西の下の角）にして建てる
   - `!build 名前 x y z` / `!build 名前 here`（ボットの少し先）
   - `!stop`、`!status`、`!materials 名前`（必要な素材の一覧）、`!list`、`!come`
   - サーバーのコンソール側からは、`data/control.txt` に同じコマンドを 1 行ずつ書いても指示できます。
6. 状態は http://localhost:3008/ で見られます。建築の指示は `data/job.json` に残り、再起動すると続きから建てます。
7. 起動してすぐ建てたい場合は `.env` に `BUILD_FILE=名前` と `BUILD_ORIGIN=x,y,z`（または `here`）を書きます。

### 試験用の道具
- `node scripts/make-sample-hut.js` … 集められる素材だけで作る小屋の設計図 `schematics/sample-hut.litematic` を作ります。
- `node scripts/make-sample-stocked.js` … コンクリート・色付き羊毛・石レンガ・突き出た梁のある小屋 `schematics/sample-stocked.litematic`（素材を用意してもらうモードの確認用）を作ります。
- `node scripts/make-castle.js` … 2×2 チャンク（32×32×14、3168 ブロック）のお城 `schematics/castle-2x2.litematic`（四隅の塔・城壁と胸壁・城門・本丸）を作ります。
- `node scripts/make-sample-tower.js` … 高さ 13 の見張り塔 `schematics/sample-tower.litematic`（はしご・窓・張り出したバルコニー。素材はチェスト 2 個分）を作ります。
- `node scripts/inspect.js 名前 x y z` … 観察用のボットで接続し、設計図と実際のブロックを比べて違うマスを一覧にします。
- `node scripts/stock-chests.js 名前 プレイヤー名` … 設計図に要る素材をチェストに入れて、そのプレイヤーの近くに並べます（RCON を使うので、試験鯖の `server.properties` で `enable-rcon=true` にして `RCON_PASSWORD` を渡します）。

## 設定（環境変数）
| 名前 | 既定 | 内容 |
| --- | --- | --- |
| `MC_HOST` / `MC_PORT` | 127.0.0.1 / 25572 | 接続先 |
| `MC_USERNAME` | BuilderBot | ボットの名前 |
| `BUILD_OWNERS` | kanetyyy | 指示できるプレイヤー（カンマ区切り） |
| `SCHEMATIC_DIR` | schematics | 設計図のフォルダ |
| `BUILD_SUPPLY` | gather | 素材のそろえ方。`stocked` は手持ちとチェストに用意した素材だけで建てる、`gather` は足りない物を自分で集める |
| `BUILD_CLEAR` | true | 建築範囲の邪魔なブロックをどける |
| `BUILD_PREPARE_TOOLS` | true | 最初に石の道具をそろえる（`gather` のとき。`stocked` ではチェストにある道具を持つだけ） |
| `BUILD_CHEST_RADIUS` | 16 | 素材を探すチェストの範囲（建築範囲の端から） |
| `BUILD_RETRY_WAIT_SEC` | 60 | 素材が足りないとき、チェストを見直すまでの秒数 |
| `BUILD_SHELTER_AT_NIGHT` | true | 夜は穴にこもって朝を待つ |
| `BUILD_USE_BED` | true | 昼のうちにベッドを作り、夜は穴の中で寝る |
| `BUILD_GATHER_BUDGET` | 800 | 1 回に自分で集める手間の上限（原木 1 本 ≒ 1、精錬やクラフトの分も足す）。超える量はチェストに入れてもらう |
| `STATUS_PORT` | 3008 | 状態ページ（0 で無効） |
| `BUILD_DEBUG` | （空） | 1 にすると、2 秒以上かかった設置や、経路探索が足場を置けなかった理由をログに出す |

## 制限
- シルクタッチが要るブロック（草ブロックなど）は土で代わりに置きます。羊毛以外の動物素材・ネザーやエンドの素材・取引でしか手に入らない物は、チェストに入れてもらう前提です。
- ドアの蝶番、柵や窓ガラスのつながり方など、周りのブロックで自動で決まる性質は合わせません。
- チェストの中身・看板の文字などのブロックエンティティの中身は再現しません。
- 素材を用意してもらうモードでは、チェストに入れたシュルカーボックス（アイテム）の中身は取り出せません。シュルカーボックスは地面に置いておけば、ほかのチェストと同じように使います。
- 屋根の真下のように狭い所では、置くのに失敗した素材をなくすことがあります（足りなくなった分はチャットで伝えるので、チェストに足せば続きを建てます）。
- 高い建物や大きな像では、置ける位置まで足場を組んで登るので時間がかかります（高さ 13 の塔 436 ブロックで 30 分ほど）。足場用の土などは、建て始めにボットが目安の数を伝えます（塔なら 192 個ほど）。
- 足場がほかの足場や建物に囲まれて見えなくなると、片付けられずに 1〜2 個残ることがあります。
- バージョンは DragonBot と同じく 1.21.11 です（Mineflayer の対応範囲）。
