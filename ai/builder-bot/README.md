# BuilderBot（Litematica 設計図の自動建築ボット）

Litematica の設計図（`.litematic`）を読み込み、サバイバルで素材をそろえて、設計図どおりに 1 段ずつ建てるボットです。
移動・採掘・クラフト・精錬などの体の動きは DragonBot（`ai/dragon-bot`）のものをコピーして使っています（DragonBot 側には手を入れていません）。

## できること
- **設計図の読み込み**: 複数の領域、負の向きのサイズ、long をまたいで詰められたブロック状態に対応（`src/building/litematic.js`）。Blender から変換した `sample-monkey.litematic`（4810 ブロック）を読めることをテストで確認しています。
- **素材の調達**（`src/building/acquire.js`）: 足りない素材は、次の中から手間の少ない方法を選んでそろえます。レシピの材料も同じ方法で再帰的にそろえます。
  1. 建築現場の近くのチェスト・樽から取る
  2. 自然にあるブロックを掘る（原木・丸石・土・砂・砂利・粘土・花・鉱石。鉱石が見えなければその高さで横掘り）
  3. 精錬する（ガラス・石・レンガ・テラコッタ・インゴットなど）
  4. 動物から取る（白い羊毛・革・羽根）
  5. クラフトする（板材・ハーフブロック・階段・ドア・松明・色付き羊毛・コンクリートパウダーなど）
  6. コンクリートは、パウダーを水辺に置いて固めてから掘る
- **建築**（`src/building/builder.js`）: 下の段から順に、邪魔な地形をどけ、手持ちに入る分ずつ素材をそろえ、近い順に置きます。
  - 向きのあるブロック（原木の軸・階段・ドア・かまど・壁の松明・ハーフブロックの上下・看板の向きなど）は、クリックする面と向く方向をバニラの決まりに合わせて置きます。
  - 下に支えの無いブロックは、真下に仮の足場を積んでから置き、最後に足場を片付けます。
  - 経路探索には「建てたブロックは壊さない」を教えてあります。
  - 毎回いまの世界の状態を見て、設計図どおりでないマスだけを置くので、中断・再起動・死亡のあとも続きから建てます。
- **反射と安全**: 敵が近づいたら建築を止めて戦い、クリーパーや体力が少ないときは離れます。食事は自動です。
  - 夜は地面に穴を掘ってこもり、朝を待ちます（防具なしで夜に建て続けると、スケルトンに倒されて素材を落としていたため）。体力が少ないときも同じように休みます。
  - 死んだら、落とした物が消える前に拾いに戻り、建築現場へ戻って続きを建てます。
  - 2 分間まったく動きが無ければ、固まったとみなしてやり直します。
- 手に入らない素材（ダイヤブロックなど）は、ある分だけ置いて先へ進み、最後に足りない物をチャットで伝えます。チェストに入れると、しばらくして続きを建てます。

## 動かし方（Windows）
1. 試験鯖を用意します: `powershell -ExecutionPolicy Bypass -File scripts\setup-test-server.ps1`。作成先は `Documents\ClaudeCode\builder-bot-test`（127.0.0.1:25572、kanetyyy が OP）です。その後 `start.bat` で起動します。
2. `npm install`
3. `.env.example` を `.env` にコピーします。
4. `node --env-file=.env src/main.js`
5. 設計図は `schematics/` に置きます。ゲーム内で（`BUILD_OWNERS` のプレイヤーが）チャットで指示します。
   - `!build 名前` … 自分の足元を設計図の最小角（北西の下の角）にして建てる
   - `!build 名前 x y z` / `!build 名前 here`（ボットの少し先）
   - `!stop`、`!status`、`!materials 名前`（必要な素材の一覧）、`!list`、`!come`
   - サーバーのコンソール側からは、`data/control.txt` に同じコマンドを 1 行ずつ書いても指示できます。
6. 状態は http://localhost:3008/ で見られます。建築の指示は `data/job.json` に残り、再起動すると続きから建てます。
7. 起動してすぐ建てたい場合は `.env` に `BUILD_FILE=名前` と `BUILD_ORIGIN=x,y,z`（または `here`）を書きます。

### 試験用の道具
- `node scripts/make-sample-hut.js` … 集められる素材だけで作る小屋の設計図 `schematics/sample-hut.litematic` を作ります。
- `node scripts/inspect.js 名前 x y z` … 観察用のボットで接続し、設計図と実際のブロックを比べて違うマスを一覧にします。
- `node scripts/stock-chests.js 名前 プレイヤー名` … 設計図に要る素材をチェストに入れて、そのプレイヤーの近くに並べます（RCON を使うので、試験鯖の `server.properties` で `enable-rcon=true` にして `RCON_PASSWORD` を渡します）。

## 設定（環境変数）
| 名前 | 既定 | 内容 |
| --- | --- | --- |
| `MC_HOST` / `MC_PORT` | 127.0.0.1 / 25572 | 接続先 |
| `MC_USERNAME` | BuilderBot | ボットの名前 |
| `BUILD_OWNERS` | kanetyyy | 指示できるプレイヤー（カンマ区切り） |
| `SCHEMATIC_DIR` | schematics | 設計図のフォルダ |
| `BUILD_CLEAR` | true | 建築範囲の邪魔なブロックをどける |
| `BUILD_PREPARE_TOOLS` | true | 最初に石の道具をそろえる |
| `BUILD_CHEST_RADIUS` | 16 | 素材を探すチェストの範囲（建築範囲の端から） |
| `BUILD_RETRY_WAIT_SEC` | 60 | 素材が足りないとき、チェストを見直すまでの秒数 |
| `BUILD_SHELTER_AT_NIGHT` | true | 夜は穴にこもって朝を待つ |
| `STATUS_PORT` | 3008 | 状態ページ（0 で無効） |

## 制限
- シルクタッチが要るブロック（草ブロックなど）は土で代わりに置きます。羊毛以外の動物素材・ネザーやエンドの素材・取引でしか手に入らない物は、チェストに入れてもらう前提です。
- ドアの蝶番、柵や窓ガラスのつながり方など、周りのブロックで自動で決まる性質は合わせません。
- チェストの中身・看板の文字などのブロックエンティティの中身は再現しません。
- バージョンは DragonBot と同じく 1.21.11 です（Mineflayer の対応範囲）。
