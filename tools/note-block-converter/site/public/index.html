oto2noteblock ブラウザで変換 Windows 版 使い方 オプション よくある質問
無料・Minecraft Java 版 1.19.4〜26.2

好きな曲を
音ブロックで鳴らそう

MIDI や音声ファイルを入れるだけで、音ブロック演奏装置の設計図（Litematica・WorldEdit）と、ゲーム内の音や演出付きでコマンドから鳴らすデータパックができます。

ブラウザで変換する Windows 版をダウンロード

ブラウザ版は、ファイルをどこにも送らずにあなたのパソコンの中だけで変換します。

反復装置 → 音ブロック → 反復装置 … の列を、同時に鳴る音の数だけ並べます

できること

入れたファイルから、目的に合わせて 5 種類のファイルを作ります。

🧱

装置の設計図

.litematic（Litematica）と .schem（WorldEdit）。スタートボタン 1 つで全部の列が同時に鳴ります。長い曲は箱形に折り返せます。

✨

コマンド版データパック

装置なしで /function から再生。0.05 秒刻みで鳴り、音の強弱、ゲーム内の音の重ね、音符のパーティクルや花火の演出付き。

🎼

Note Block Studio 用 .nbs

試聴や手直しに。直した .nbs をもう一度入れれば、そのまま装置にできます。

🎤

音声からも

MP3・WAV などは、Spotify の採譜 AI「Basic Pitch」で楽譜にしてから変換します（Windows 版）。

🎯

実機で確かめ済み

バニラ 1.19.4 と 26.2 の鯖で、全部の音ブロック・全部のコマンドが予定どおりのタイミングで鳴ることを確認しています。

🎚️

リズムのよれを直す

レッドストーンは 0.1 秒刻み。テンポが合わない曲は、少しだけ速さを変えてリズムを等間隔にできます（--fit-tempo）。

ブラウザで変換

MIDI（.mid）か Note Block Studio の .nbs を入れてください。インストールは要りません。

🎵
ここにファイルをドロップ
またはクリックして選ぶ（.mid / .midi / .nbs）
音声ファイル（MP3・WAV など）はブラウザでは楽譜にできません。Basic Pitch で MIDI にしてから入れるか、Windows 版に直接入れてください。

    Windows 版
    
  
    音声ファイル（MP3・WAV など）から変換したい時や、曲をまとめて変換したい時に。ドラッグ＆ドロップで使えます。
    
  
    
    Windows 版をダウンロード（zip）
  
    
  
    v1.0.0
    
  
      
    
    1. Python（3.10 以上）を入れる。インストールの最初の画面で 「Add python.exe to PATH」にチェックを入れてください。
      2. 
    
    2. zip を展開し、setup.bat をダブルクリック。音声も変換したい時は、途中の質問に Y（約 300MB ダウンロード）。
      3. 
    
    3. 曲のファイルを convert_26.2.bat か convert_1.19.4.bat にドラッグ＆ドロップ。曲と同じフォルダに設計図などができます。
      4. 
  
    
  
    ほかのバージョンや細かい設定は、同じフォルダでコマンドから使えます。例: venv\Scripts\python oto2noteblock.py 曲.mid --mc 1.21.11 --fit-tempo（オプションは下の表）。
    

    


    
  
    使い方
    
  
    装置を建てる（.litematic）
    
  
      
    
    1. できた 曲名.litematic を、Minecraft のフォルダの schematics に入れる。
      2. 
    
    2. Litematica のメニュー（M キー）→「Load Schematics」で読み込み、平らな場所に置く。クリエイティブなら設置の手助け（Easy Place など）を使うと早いです。
      3. 
    
    3. 設計図の角（いちばん手前・左）にあるボタンを押すと演奏が始まります。
      4. 
  
    
  
    音ブロックの真上は空気にしておいてください。長い曲は近くのチャンクが読み込まれている間しか鳴らないので、折り返し（箱形）がおすすめです。WorldEdit なら 曲名.schem を //schem load で。
    
  
    コマンドで鳴らす（データパック）
    
  
      
    
    1. 曲名_datapack.zip を、ワールドのフォルダの datapacks にそのまま入れる（展開しない）。
      2. 
    
    2. ゲームで /reload（鯖ならコンソールでも可）。
      3. 
    
    3. /function 名前:play で自分に、/function 名前:play_all で全員に流す。/function 名前:stop で止める。
      4. 
  
    
  
    「名前」は変換のときに表示されます（例: mysong:play）。日本語の曲名だと song_1a2b3c のような名前になるので、上の「名前」の欄で決めておくと覚えやすいです。
    
  
    設置用 .mcfunction
    
  
    曲名_place.mcfunction は、データパックの関数として実行すると、実行した人の足元を角にして装置を組み立てます。
    

    


    
  
    オプション（Windows 版・コマンド）
    
  
    python oto2noteblock.py 曲.mid [オプション]
    
  
    
    
    オプション意味
    
    
    --mc 1.19.4バージョン（既定 26.2。ほか 1.21.11、1.21.4、1.21.1、1.20.4、1.20.1、1.19.4）
    
    
    --row-length 6464 ブロックごとに上へ折り返して箱形に（0 で一直線）
    
    
    --max-lanes 12同時に鳴らす音の最大数。多いほど原曲に近いが装置が太くなる（1 列 3 ブロック幅）
    
    
    --fit-tempoテンポを 0.1 秒刻みに合わせ、リズムのよれを直す（例: 179 BPM → 約 150 BPM）
    
    
    --speed 0.9速さの倍率
    
    
    --instruments pitch楽器を高さだけで決める。single:bell で全部同じ楽器
    
    
    --min-velocity 40弱い音を捨てる（音声から作って雑音が多い時に）
    
    
    --onset 0.7音声解析で音の出だしを厳しく（音が多すぎる時は上げる）
    
    
    --formats litematic,datapack作るファイルを選ぶ（litematic, schem, nbs, mcfunction, datapack）
    
    
    --sounds gameデータパックで、音ブロックの音にゲーム内の音を重ねる。自分の対応表 .json も指定可
    
    
    --effects fullデータパックの演出（none / basic / full）
    
    
    --stage X Y Zデータパックを、聞く人の位置ではなく決まった場所から鳴らす（--stage-volume 4 で 64 ブロック先まで）
    
    
    --loopデータパックで、最後まで行ったら繰り返す
    
    
    --dp-id mysongデータパックの名前（/function mysong:play）
    
    
    --rcon 127.0.0.1:25575 --rcon-password PW --origin X Y Z鯖に RCON で直接建てる
    
  
    

    


    
  
    よくある質問
    
  
    音が多すぎる・外れている
    音声から作った時に起きやすいです。歌入りの曲より、楽器のソロやピアノの耳コピ音源が向いています。曲名.nbs を Note Block Studio で開いて、いらない音を消してから入れ直すときれいになります。
    
  
    リズムが少しよれる
    音ブロックはレッドストーンの 0.1 秒刻みでしか鳴らせません。「テンポを 0.1 秒刻みに合わせる」（--fit-tempo）を使うと等間隔になります。データパック版は 0.05 秒刻みなので、よれが小さくなります。
    
  
    音が途中で止まる
    装置が長すぎて、遠くのチャンクが読み込まれていないためです。折り返し（箱形）にするか、データパック版を使ってください。
    
  
    データパックが有効にならない
    /datapack list で確かめ、「使える」側にあれば /datapack enable "file/ファイル名.zip" で有効にしてください。バージョンは変換のときに合わせたものを使ってください。
    
  
    ブラウザ版でファイルは送られる？
    送られません。Python（Pyodide）をブラウザに読み込み、あなたのパソコンの中だけで変換します。
