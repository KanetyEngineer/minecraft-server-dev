# BlockMotion（マイクラ3Dアニメ自動生成）

スキン画像を選んで、モーションを並べて、ボタンを押すだけで、マイクラ風の 3D アニメーション動画と Blender ファイル（.blend）を作る Windows 用デスクトップアプリです。PC にインストールされた Blender を裏で動かします。

## 必要なもの

- Windows 10 / 11
- Blender 4.2 以降（5.0 で確認）。https://www.blender.org/download/ からインストールしてください。Steam 版や Microsoft Store 版も自動で見つけます。

## 使い方

1. `BlockMotion-windows.zip` を展開して、`BlockMotion\BlockMotion.exe` を起動します。
2. 一番上の「Blender」欄に blender.exe の場所が入っていることを確認します（空なら「自動検出」か「参照…」）。
3. 左のタブを順に設定します。
   - **① キャラクター**: 出演者（最大 8 人）ごとにスキン・持ち物・立ち位置と向き・モーションの再生リストを決めます。「＋追加」「複製」で出演者を増やせます。腕の太さ（Steve 型 / Alex 型）は自動判定です。
   - **② カメラ**: カメラの種類を 1 つ選ぶか、「カット割り」にカメラ・映す相手・秒数を並べると、その順にカメラが切り替わります。背景ぼかし（被写界深度）もここです。
   - **③ 背景**: 背景・時間帯（昼 / 夕焼け / 夜）・天気（晴れ / 雨 / 雪）。マイクラのワールドも読み込めます（下の「ワールドを背景にする」）。
   - **④ 演出**: 最初に出すタイトル、映画風の黒帯、字幕（開始秒・終了秒・セリフ）。
   - **⑤ 書き出し**: サイズ（TikTok 用の縦長もあります）・画質・FPS・保存先。
4. 「プレビュー」で 1 コマだけ描いて確認し、良ければ「▶ アニメを生成」。
5. 設定一式は「ファイル」→「プロジェクトを保存…」で `.bmproj` に保存して、あとで開き直せます。

できあがるもの（保存先フォルダ）:

| ファイル | 中身 |
| --- | --- |
| `名前.mp4` | 動画（H.264） |
| `名前.blend` | Blender ファイル。リグ（ボーン）とキーフレーム付きなので、Blender で開いて手直しできます |
| `名前_frames\` | 背景「透過」のときの PNG 連番（背景なし） |
| `名前_preview.png` | プレビュー画像 |

## モーション（53 種類）

| 分類 | モーション |
| --- | --- |
| 移動 | 歩く / 走る / 後ろ歩き / スニーク歩き / スキップ / ゾンビ歩き / ほふく前進 / 泳ぐ / 空を飛ぶ / よじ登る |
| 向き | 左を向く / 右を向く / 振り返る / くるっと回る |
| 基本 | 待機 / 見回す / しゃがむ / 座る / 寝転ぶ / Tポーズ / 伸び / ジャンピングジャック |
| 気持ち | 手を振る / お辞儀 / うなずく / 首を横に振る / 拍手 / バンザイ / ガッツポーズ / 大笑い / 泣く / 落ち込む / 地団駄 / 怖がる / 頭を抱える / 肩をすくめる / 指さす / 敬礼 |
| 作業 | 採掘 / 食べる / 投げる |
| 戦闘 | 剣を振る / パンチ / キック / 盾で防ぐ / 弓を引く / 倒れる / やられる |
| アクション | ジャンプ / バク宙 |
| ダンス | ダンス / フロス / ダブ |

つなぎ目は自動でなめらかにつながります。「向き」のモーションのあとは向いた方向のまま次のモーションに進み、「倒れる」「やられる」のあとは倒れたままになります。「歩く・走るで前に進む」をオフにすると、その場で足踏みします。

## カメラ（16 種類）

ななめ前 / 正面 / 真横 / 後ろ / アップ / ローアングル / 見下ろし / 遠景 / 真上 / ぐるっと回る / ズームイン / ズームアウト / 上昇（クレーン）/ 横移動 / 主観（目線）/ 肩越し

カット割りでは、カットごとに「全員」か特定のキャラを映せます。肩越しは、ほかの出演者の側から選んだキャラを撮ります（会話シーン向け）。

## 背景

草原（木と花）/ 砂漠 / 雪原 / 洞窟（鉱石と松明）/ ネザー / エンド / マイクラのワールド / スタジオ（好きな単色）/ グリーンバック（動画編集アプリで切り抜き用）/ 透過（PNG 連番）

## ワールドを背景にする

自分のワールドの好きな場所をそのまま撮影セットにできます。

1. ③ 背景で「マイクラのワールドを読み込む」を選び、ワールドフォルダ（例: `%APPDATA%\.minecraft\saves\ワールド名`、サーバーなら `world` フォルダ）を選びます。
2. 中心の座標に、ゲーム内で F3 を押して表示される X / Y / Z を入れます。「プレイヤーの位置を読み込む」で、最後にいた場所を入れることもできます。
3. 読み込む範囲（半径・下・上のブロック数）を決めます。広いほど時間がかかります（半径 32 くらいがおすすめ）。
4. テクスチャは PC にある Minecraft 本体（`.minecraft\versions\<バージョン>\<バージョン>.jar`）から読みます。「自動検出」で見つかります。リソースパック（zip かフォルダ）も重ねられます。

キャラの立ち位置（X / Z）は中心座標からのずれで、キャラは足元の地面の高さに自動で立ちます。向きの「南・西・北・東」はゲーム内の方角と同じです。Java 版 1.13 以降のワールド（1.18 以降の高さ拡張にも対応）を読めます。

## 画質の目安

- 標準（EEVEE）: GPU で速く描きます。ふだんはこれ。
- 高画質（Cycles）: 光と影がきれいですが時間がかかります。NVIDIA / AMD / Intel の GPU があれば自動で使います。
- 下書き（Workbench）: 最速。動きの確認用です。

## exe が開けないとき

Windows の「スマート アプリ コントロール」や SmartScreen が署名のない exe を止めることがあります。その場合は、ダウンロードした zip を右クリック →「プロパティ」→「許可する」にチェックしてから展開するか、Python 3.10 以降を入れて `run_source.bat` から起動してください（ソース一式はリポジトリの `tools/blockmotion/`）。

## コマンドラインで使う

GUI なしでも動きます。設定 JSON の例:

```json
{
  "actors": [
    {"skin": "C:/Users/me/a.png", "x": 0, "z": 0, "yaw": 0, "item": "diamond_sword",
     "motions": [{"id": "walk", "seconds": 3}, {"id": "wave", "seconds": 2}]},
    {"skin": "C:/Users/me/b.png", "x": 1, "z": 3, "yaw": 180,
     "motions": [{"id": "idle", "seconds": 3}, {"id": "clap", "seconds": 2}]}
  ],
  "shots": [{"camera": "wide", "target": "all", "seconds": 2},
            {"camera": "over_shoulder", "target": 0, "seconds": 3}],
  "background": "world",
  "world": {"path": "C:/Users/me/AppData/Roaming/.minecraft/saves/MyWorld", "dimension": "overworld",
            "x": 100.5, "y": 64, "z": -200.5, "radius": 32, "down": 16, "up": 40,
            "client_jar": "C:/Users/me/AppData/Roaming/.minecraft/versions/1.21.11/1.21.11.jar"},
  "time": "sunset", "weather": "rain",
  "title": "はじまり", "letterbox": true,
  "subtitles": [{"start": 1, "end": 3, "text": "やあ！"}],
  "resolution": [1920, 1080], "fps": 24, "engine": "eevee",
  "output_dir": "C:/Users/me/Videos/BlockMotion", "name": "test"
}
```

```
blender -b --factory-startup -P blender/generate.py -- config.json
```

モーション ID は `blender/bm_motions.py` の `MOTION_INFO`、カメラ ID は diagonal / front / side / back / closeup / low / high / wide / top / orbit / dolly_in / dolly_out / crane / track / pov / over_shoulder です。v1 の書き方（`skin` と `motions` を直接書く）もそのまま使えます。

## 補足

- 背景とアイテムのテクスチャは Minecraft のものです（Mojang Studios）。作った動画の公開は Minecraft の利用ガイドラインの範囲で行ってください。
- 画面の言語は「言語 / Language」メニューで日本語と英語を切り替えられます（最初は Windows の言語に合わせます）。
- 設定は `%APPDATA%\BlockMotion\settings.json` に保存されます。
- ワールドを読み込むときのテクスチャは、PC にある Minecraft 本体から読むだけで、配布物には含めていません。
