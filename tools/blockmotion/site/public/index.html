マイクラの3Dアニメを
ボタンひとつで。

スキンを選んで、モーションを並べて、「生成」を押すだけ。PC の Blender が裏で動いて、動画（MP4）と手直しできる Blender ファイルを作ります。

⬇ 無料でダウンロード できることを見る

Windows 10 / 11・Blender 4.2 以降（無料）が必要です

使い方は 3 ステップ

Blender の操作を知らなくても大丈夫です。

スキンを選ぶ

いつものスキン画像（64×64 の PNG）を選ぶだけ。腕の太さ（Steve 型 / Alex 型）は自動で見分けます。最大 8 人まで出演できます。

動きとカメラを並べる

53 種類のモーションから選んで再生リストに追加。つなぎ目は自動でなめらかに。カット割りでカメラも切り替えられます。

「生成」を押す

プレビューで 1 コマ確認してから生成。YouTube 用の横長も、TikTok 用の縦長も書き出せます。

ちょっとした映画が撮れる

会話シーンも、旅立ちのシーンも、自分のワールドで。

APPタブを順に埋めるだけ

キャラクター、カメラ、背景、演出、書き出しの 5 つのタブを上から順に決めていきます。設定はプロジェクトファイルに保存して、あとから続きを作れます。

  • Blender の場所は自動で見つけます
  • 進み具合とプレビューをアプリ内に表示
  • できた .blend はリグとキーフレーム付き

WORLD自分のワールドが撮影セットに

ワールドフォルダを選んで、F3 で表示される X / Y / Z を入れるだけ。その周りのブロックをそのまま読み込んで背景にします。

  • 「プレイヤーの位置を読み込む」で最後にいた場所を自動入力
  • 読み込む範囲（半径・上下）を指定
  • テクスチャは PC の Minecraft 本体から。リソースパックも使えます
  • Java 版 1.13 以降のワールドに対応

DIRECTINGカット割り・字幕・天気

16 種類のカメラを、映す相手と秒数を決めて並べられます。会話シーン向けの「肩越し」や、キャラの目線の「主観」もあります。

  • カメラ：ななめ前 / アップ / 遠景 / 肩越し / 主観 / ズームイン / クレーン / ぐるっと回る など
  • タイトル、字幕、映画風の黒帯、背景ぼかし
  • 時間帯（昼・夕焼け・夜）と天気（雨・雪）

OUTPUT動画と .blend を書き出し

MP4（H.264）でそのまま投稿できます。Blender ファイルも一緒に保存されるので、細かい動きやライトを自分で直すこともできます。

  • 横長 1920×1080 / 縦長 1080×1920 / 正方形 / 4K
  • 画質は 標準（EEVEE）/ 高画質（Cycles）/ 下書き
  • グリーンバックと透過 PNG 連番で動画編集アプリにも

よくある質問

困ったときはここを見てください。

exe が開けない・「Windows によって PC が保護されました」と出る

署名のないアプリなので、Windows の SmartScreen やスマート アプリ コントロールが止めることがあります。

  1. ダウンロードした zip を右クリック →「プロパティ」→ 下の「許可する」にチェック →「OK」
  2. そのあと zip を展開して BlockMotion\BlockMotion.exe を起動
  3. 青い画面が出たら「詳細情報」→「実行」

それでも開けないときは、Python 3.10 以降を入れて、ソース一式の run_source.bat から起動できます。

Blender が見つからないと言われる

アプリ上の「自動検出」を押すか、「参照…」で blender.exe を選んでください。ふつうは C:\Program Files\Blender Foundation\Blender 5.0\blender.exe にあります。

生成にどれくらい時間がかかる？

PC の性能と画質によります。まず「プレビュー」で 1 コマ描いて確認し、動きだけ見たいときは画質を「下書き」にすると速く終わります。高画質（Cycles）は GPU があると速くなります。

ワールドが読み込めない

ワールドフォルダは %APPDATA%\.minecraft\saves\ワールド名（サーバーならサーバーフォルダの world）を選んでください。座標は F3 の「XYZ」の値です。テクスチャ欄に Minecraft 本体の jar（.minecraft\versions\バージョン\バージョン.jar）が入っているかも確認してください。

作った動画を YouTube や TikTok に投稿していい？

はい。ただし背景やアイテムのテクスチャは Minecraft のものなので、Minecraft の利用ガイドラインの範囲で使ってください。
