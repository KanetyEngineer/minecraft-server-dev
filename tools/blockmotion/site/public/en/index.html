FAQ

Check here if you get stuck.

The exe won’t open / “Windows protected your PC”

The app isn’t code-signed, so Windows SmartScreen or Smart App Control may block it.

  1. Right-click the downloaded zip → “Properties” → tick “Unblock” at the bottom → “OK”
  2. Then unzip it and run BlockMotion\BlockMotion.exe
  3. If a blue screen appears, click “More info” → “Run anyway”

If it still won’t start, install Python 3.10 or later and launch run_source.bat from the source code.

It says Blender can’t be found

Press the auto-detect button (自動検出) in the app, or use browse (参照…) to select blender.exe. It is usually at C:\Program Files\Blender Foundation\Blender 5.0\blender.exe.

How long does rendering take?

It depends on your PC and the quality setting. Render a single frame with Preview (プレビュー) first; set quality to Draft (下書き) when you only want to check the motion. High quality (Cycles) is much faster with a GPU.

My world won’t load

Select the world folder at %APPDATA%\.minecraft\saves\<world name> (for a server, the world folder in the server directory). The coordinates are the “XYZ” values on the F3 screen. Also check that the texture field points to the Minecraft jar (.minecraft\versions\<version>\<version>.jar).

Can I post my videos on YouTube or TikTok?

Yes. The background and item textures belong to Minecraft, so please follow the Minecraft Usage Guidelines.
