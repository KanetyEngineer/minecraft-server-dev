# 性能比較: Blender to Litematic / ObjToSchematic / drububu Voxelizer

2026-10-02 測定。同じ PC 環境（クラウドの Linux、CPU のみ）で 1 つずつ実行。

## 比べたもの

| | 今回のアドオン (v1.0.1) | ObjToSchematic (2025-04 版) | drububu Voxelizer |
|---|---|---|---|
| 動く場所 | Blender の中 | ブラウザ（今回は同じコードを Node.js で実行） | ブラウザ |
| 出力 | .litematic（26.2 向け、v7） | .litematic（1.19 向け、v5）/ .schem / .nbt / .schematic | .schematic ほか多数（.litematic なし） |
| 入力 | Blender で開けるものすべて（モディファイア込み） | .obj / .glb | .obj / .stl / .vox など |
| 色の元 | 画像テクスチャ・頂点カラー・マテリアル色 | テクスチャ・マテリアル色 | テクスチャ（.obj） |
| 中を埋める | あり | なし | 殻の厚さを指定 |
| ディザ（点描） | なし | あり（既定オン） | 不明 |

drububu はこの環境からサイトに接続できず、実測できていません。表は公開されている説明だけからまとめたものです。

## テストモデル

- **頭蓋骨**: ObjToSchematic 付属のサンプル（写真テクスチャ、約 1 万面）
- **シーン**: スザンヌ＋細い棒（ブロック 1 個より細い）＋斜めの板＋床。縞模様のテクスチャ

どちらも高さ 64 / 128 / 256 ブロックに変換。

## 速度（変換にかかった秒数）

| モデル・高さ | 今回のアドオン | ObjToSchematic |
|---|---|---|
| 頭蓋骨 64 | 2.2 | 2.0 |
| 頭蓋骨 128 | 3.8 | 5.4 |
| 頭蓋骨 256 | **12.0** | 14.3 |
| シーン 64 | 2.3 | 1.3 |
| シーン 128 | 8.1 | 4.6 |
| シーン 256 | 31.1 | **23.3** |

ObjToSchematic は既定の ray-based 方式（読み込み〜書き出しの合計）。アドオンは今回の比較で見つけた遅い箇所（ブロック配列の書き込みと圧縮）を直した後の値。直す前は頭蓋骨 256 が 23.6 秒、シーン 256 が 64.1 秒でした。

## 仕上がり

| モデル・高さ | ツール | ブロック数 | 置くべき所の再現率 | 余計なブロック | 色の差 ΔE（平均 / 90%点） |
|---|---|---|---|---|---|
| 頭蓋骨 64 | アドオン | 35,392 | 100% | 0% | **5.2** / 8.1 |
| | ObjToSchematic | 20,320 | 95% | 0% | 9.5 / 15.1 |
| 頭蓋骨 128 | アドオン | 142,746 | 100% | 0% | **5.1** / 7.8 |
| | ObjToSchematic | 83,540 | 78% | 0% | 9.4 / 15.0 |
| 頭蓋骨 256 | アドオン | 572,836 | 100% | 0% | **5.1** / 7.6 |
| | ObjToSchematic | 338,857 | 75% | 0.6% | 9.3 / 15.0 |
| シーン 64 | アドオン | 39,519 | 100% | 0% | **8.9** / 11.2 |
| | ObjToSchematic | 30,301 | 69% | 0.3% | 11.6 / 18.3 |
| シーン 128 | アドオン | 157,576 | 100% | 0% | **8.8** / 11.2 |
| | ObjToSchematic | 123,527 | 71% | 0.3% | 12.3 / 21.7 |

- **再現率**: 表面がブロックの中心近く（0.3 ブロック以内）を通るのにブロックが置かれていない所がないか。
- **余計なブロック**: 表面がまったく触れていない所に置かれたブロックの割合。
- **色の差**: 元のモデルのその場所の色と、置かれたブロックの平均色の差（CIEDE2000。2 以下はほぼ見分けられない、10 前後ははっきり違う）。
- シーン 256 は採点がメモリ不足で途中で止まったため載せていません。

### 読み方

- **穴**: 再現率は ObjToSchematic のほうが低いですが、殻が薄い（1 枚）ためです。頭蓋骨の外から中へ抜ける穴はどちらにもありませんでした（閉じた内側の体積がほぼ同じ）。見た目の穴の差はほぼありません。シーンの斜めの板では、ObjToSchematic の再現率が 47〜58% と特に低くなりました。
- **ブロック数**: アドオンは表面が少しでもかかるマスを埋めるので、ブロックが 1.3〜1.7 倍多くなります。サバイバルで集める量はそのぶん増えます。
- **色**: アドオンのほうが元の色に近い結果でした（平均 ΔE がおよそ半分）。ObjToSchematic は既定でディザ（点描）がかかるので、1 ブロックずつの色差では不利になります。代わりに、遠くから見たときのグラデーションはなめらかになります。画像では、ObjToSchematic の頭蓋骨に緑の点が混じっているのが見えます。
