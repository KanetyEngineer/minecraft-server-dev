# Blender to Litematic

Blender のモデルを Minecraft のブロックに変換して、Litematica の設計図（`.litematic`）として書き出す Blender アドオンです。

- 対応: Blender 4.2 以降（5.0 で動作確認済み）
- 出力: Litematica 設計図 v7、既定の Minecraft バージョンは 26.2（Data Version 4903）。1.21.4〜26.3 も選べます。
- 色合わせ: 画像テクスチャ（UV）、カラー属性（頂点カラー）、マテリアルのベースカラーから色を拾い、ブロックの平均色に CIEDE2000 色差で一番近いものを選びます。

## インストール

1. `blender_to_litematic-1.0.0.zip` を用意する（展開しない）。
2. Blender の「編集 > プリファレンス > 機能拡張（Get Extensions）」右上の ∨ から「ディスクからインストール…」を選び、zip を指定する。
   - zip を Blender の画面にドラッグ＆ドロップしても入ります。
3. 3D ビューで `N` キーを押し、サイドバーの「Litematic」タブを開く。

## 使い方

1. 変換したいオブジェクトを選択する（複数可。モディファイアは適用後の形で変換されます）。
2. 「Litematic」タブで設定する。
   - **大きさ**: 「ブロック数で指定」なら一番長い辺のブロック数、「1 ブロックの大きさで指定」なら Blender の何 m を 1 ブロックにするか。パネルにおおよその完成サイズが出ます。
   - **ブロックの種類**: 使ってよいカテゴリにチェック。既定はコンクリート・羊毛・テラコッタ・木材・石・自然・鉱物。サバイバルで集めにくいもの（ダイヤブロック等）は「除外」に `diamond_block, emerald_block` のように書けば外せます。
   - **色の決め方**: 「最頻」は色の境目がくっきり、「平均」はグラデーションがなめらか。
   - **中を埋める**: オンにすると閉じた形の内側を「中身のブロック」で埋めます。オフなら外殻だけ（サバイバル建築向き）。
   - **色の元**: 空なら同梱のバニラ 26.2 の色。リソースパックの zip やクライアント jar を指定すると、その見た目で色を計算します。
3. 「Litematic に書き出す」を押して保存先を選ぶ（「ファイル > エクスポート > Litematica (.litematic)」からも可）。
4. 「プレビューも作る」がオンなら、元のモデルの右隣に変換結果がブロックの形で表示されます。マテリアルプレビュー表示か、ソリッド表示の色を「属性」にすると色が見えます。
5. できた `.litematic` を `.minecraft/schematics`（PrismLauncher ならインスタンスの `minecraft/schematics`）に入れ、ゲーム内で Litematica の「Load Schematics」から読み込みます。

向き: Blender の正面図（テンキー 1）で見た形が、北を向いて立ったときに見える形になります。Blender の上（Z）が Minecraft の上（Y）です。

## 設定のコツ

- 細い部分（指・アンテナなど）は、ブロック数を増やすか、元のモデルで太くしておくと残りやすいです。
- 透明な部分（テクスチャのアルファが 0.5 未満）はブロックになりません。葉っぱのテクスチャなどもそのまま抜けます。
- 「中を埋める」は形が閉じていることが前提です。穴の大きいメッシュでは中が埋まらないことがあります。
- 重力で落ちるブロック（砂・コンクリートパウダー）と色付きガラスは既定で使いません。必要ならカテゴリにチェックを入れてください。

## ファイル構成（開発者向け）

| ファイル | 役割 |
| --- | --- |
| `__init__.py` | Blender の UI とオペレーター |
| `blender_source.py` | オブジェクトから三角形と色（テクスチャ・頂点カラー・マテリアル）を取り出す |
| `voxelize.py` | 三角形の表面に点を打ってボクセル化、内部の塗りつぶし（numpy のみ） |
| `palette.py` / `palette_data.py` / `blocks.py` | ブロック一覧、平均色、色差による対応づけ |
| `litematic.py` / `nbt.py` | `.litematic`（gzip 圧縮の NBT）の読み書き |
| `preview.py` | 変換結果を Blender に表示 |
| `png.py` | テクスチャの平均色を計算するための PNG デコーダ |

- `tests/test_core.py`: Blender なしで動くテスト（`python tests/test_core.py`。`litemapy` が入っていれば独立した実装でも読めるか確認します）
- `tests/test_blender.py`: `pip install bpy` した Python で、アドオン全体を動かすテスト
- `tools/gen_palette.py`: ブロックの平均色を作り直す（`python tools/gen_palette.py <client.jar>`）

同梱の平均色は Minecraft 26.2 のバニラテクスチャから計算しています。
