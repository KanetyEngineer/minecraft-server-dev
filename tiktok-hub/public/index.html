配信者を追加

1人 = TikTok の ID ＋ Minecraft の名前。ゲームと番号（フィールド／アリーナ）を選ぶと、その配信のギフト・フォロー・シェア・いいね・コメントはそのゲームのその番号だけに届き、ゲームごとのギフト設定で演出に変わります。何人でも同時につなげます。

配信者

ゲームを変えるとその場で切り替わります（TikTok はつないだまま）。同じ番号に別の人を入れると、前の人は「割り当てなし」になります。各ゲームのパネルの「配信者」「TikTok の ID」欄で変えても、ここに反映されます。

🎁 ギフト一覧

どのギフト・フォロー・シェア・いいねで何が起きるかの一覧です。配信者を選ぶと、その人だけのギフトの割り当てを決められます（決めていない配信者はゲームの設定のまま）。割り当てはゲームごとに別々に覚えます。

OBS 用の一覧（背景は透明）

OBS の「ブラウザ」ソースにこの URL を入れます（幅は下の「幅」と同じに。高さは中身に合わせて伸びるので大きめで OK）。割り当てを変えると数秒でオーバーレイも変わります。画像で使うときは「PNG で保存」。

別のタブで開く

📺 配信ツール

TikFinity のような配信の道具です。ゲームとは別に、どの配信者にも使えます: コメントの読み上げ、フォロー・シェア・サブスク・ギフト・いいね達成・入室のアラート（効果音＋読み上げ）、ゴール（目標バー）、延長タイマー、チャット欄・最近のイベント・ランキング・カウンターの OBS 用オーバーレイ。設定は全員共通、数は配信者ごと・LIVE ごとです（新しい LIVE に接続すると 0 から）。

テスト（本物と同じ流れでアラート・読み上げ・数が動きます）

⏱️ 延長タイマー（サブアソン）

ギフトのコイン・フォロー・シェア・サブスク・いいねで時間が延びるタイマーです。OBS には右の「延長タイマー」の URL を入れます。

🔊 読み上げ

ゆっくりの声は AquesTalkPlayer（a-quest.com）で作ります。無料なのは個人の非商用だけです。収益のある配信では商用ライセンスを確かめてください。

読み上げと効果音は「アラート」のオーバーレイ（OBS のブラウザソース）から鳴ります。OBS のソースの「OBS で音声を制御する」を入れると、音量を OBS で調整できます。絵文字は読まず、URL は「URL」と読みます。

🔔 アラート

文の中の {name} は名前、{gift} はギフト名、{count} は個数、{coins} はコイン、{likes} はいいね数になります。

いつ出す文効果音読上げ

🎵 効果音

最初から入っている音のほかに、自分の mp3 / wav / ogg / m4a を足せます（8MB まで）。

🎯 ゴール

「次の目標」に数を入れると、達成したときに目標がその分だけ上がります（0 なら達成のまま）。OBS の URL の n= が上からの番号です。

💬 チャット欄・ランキング

OBS のオーバーレイ

OBS の「ブラウザ」ソースに URL を入れます（背景は透明、大きさは URL の下の数字が目安）。ゲームに割り当てた配信者は「ゲーム＋番号」の URL になり、その番号に入った人に自動で切り替わります。&size=1.5 で文字を大きく、&max= で行数を変えられます。

OBS でも鳴っているときにプレビューの音を出すと二重に聞こえます。

使うゲーム

使わないゲームを外すと、そのサーバーへの接続や旧アドレスの受け付けをしません（ハブの再起動で反映）。

前のアプリのアドレス（互換）

前は1ゲームに1つずつアプリがありました。OBS のソースやサーバーのリソースパックの URL がそのまま使えるよう、このハブは前のポートでも同じパネル・オーバーレイ・リソースパックを出します。前のアプリが動いていてポートが使われているときは、30秒ごとに取り直します。
