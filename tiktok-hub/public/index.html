1人 = TikTok の ID ＋ Minecraft の名前。ゲームと番号（フィールド／アリーナ）を選ぶと、その配信のギフト・フォロー・シェア・いいね・コメントはそのゲームのその番号だけに届き、ゲームごとのギフト設定で演出に変わります。何人でも同時につなげます。

配信者
