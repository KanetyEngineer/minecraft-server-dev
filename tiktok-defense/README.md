# TikTok Defense（銃MOD × TikTok LIVE ディフェンス）

一直線のレーンに関門が並び、奥から敵MOBが押し寄せます。プレイヤーは銃（Point Blank）で関門を守り、
TikTok LIVE の視聴者はギフトで敵を増やしたり（妨害）、空爆や修理で助けたりできます。
ギフトで出た敵の頭上には、送った人の TikTok アイコン（24×24 のドット絵）と名前が付きます。

```
コア(ビーコン) ─ 最終防衛橋 ─ 第1関門 ─ 第2関門 ─ 第3関門 ─ 敵の出現ポータル
                                                 ↑ プレイヤーはいちばん奥の関門の上で戦う
```

同じサーバーの中に **フィールド（レーン）が複数（初期 4 つ、最大 8 つ）** 並んでいて、それぞれ別々に同時進行します。
プレイヤーは待機所でフィールドを選んで入り、配信者ごとにフィールドを割り当てれば、その人の TikTok LIVE のギフトはその人のフィールドだけに届きます。
2つのフィールドを同時にスタートして競う **対戦モード** と、記録の **ランキング** もあります。

```
待機所       z = -200（看板・ランキング・遊び方。ワールドのスポーン）
フィールド1  z =    0  ← 元のフィールドと同じ場所
フィールド2  z =  200
フィールド3  z =  400
フィールド4  z =  600   （数と間隔はパネルで変更）
```

| 連動アプリ | まとめアプリ `..\tiktok-hub`（パネル http://127.0.0.1:8800/ の「ディフェンス」タブ、OBS http://127.0.0.1:8800/overlay?game=defense&field=N 。旧 8788 も使える） | ギフト → 敵・効果、全設定を画面で変更、フィールドの作り直し、ゲーム開始/停止 |

| クライアント | Prism の「TikTok Defense 26.1.2」、配布用 `dist\tiktok-defense-26.1.2-1.0.1.mrpack` | Sodium + Iris + Complementary Reimagined r5.8 シェーダー、アイコン表示用リソースパック |

## 遊び方
1. `server\start-server.bat` でサーバーを起動。
2. 連動はまとめアプリ `..\tiktok-hub`（PC 起動時に自動で起動）。パネルは http://127.0.0.1:8800/ 。
3. Prism Launcher で「TikTok Defense 26.1.2」を起動し、サーバー一覧の「TikTok Defense」（localhost:25574）に入る。
4. 入ると待機所に出ます。看板の「▶ 入る」でフィールドへ。入ったらチャットの「▶ スタート」（またはパネルの「ゲーム開始」）で始まります。関門・コアが直り、そのフィールドの装備セット（初期は「標準」= M4A1・Glock17・手りゅう弾）が配られ、いちばん奥の関門の上に移動します。
5. 「接続設定」タブで、フィールドごとに配信者（マイクラの名前・TikTok の ID）を入れて保存すると、配信中のギフトでそのフィールドが動きます。ID が空でもテストギフトで試せます。

### フィールドの選び方・抜け方（プレイヤー）
- 待機所の看板を右クリック: 「フィールドN ▶ 入る」で参加、「観戦する」で見るだけ（スペクテイター）、「メニュー」でチャットに一覧、「自分の記録」、「⚔ 対戦モード」、「ゲームロビーへ」（ほかのゲームのロビーサーバーへ戻る ＝ これまでどおりの `/trigger lobby`）。
- チャットのメニュー: `/trigger td.menu`（クリックできる一覧が出ます。各フィールドの状態・残り時間・いる人・配信者が見られます）。
  - `/trigger td.menu set 1N` フィールドN に入る（例: `set 12` でフィールド2）／ `set 2N` 観戦
  - `set 2` 待機所に戻る ／ `set 3` 入っているフィールドでスタート ／ `set 4` 対戦モードの募集（もう一度でやめる）／ `set 5` 自分の記録
- ゲーム中のフィールドにも途中から参加できます（初期装備が配られます）。最後の1人が抜けるとそのフィールドは止まります。
- 抜けて入り直すと、ゲーム中のフィールドにいた人はそのフィールドに戻り、それ以外は待機所に出ます。
- サイドバーは、フィールドにいる間はそのフィールドの残り秒・敵の数・撃破数・関門・コアHP、待機所ではランキング（撃破数 → 生存 → 防衛成功 → 対戦の勝ち を順に表示）。名前の前に [F1] などが付きます。同じフィールドの人どうしは撃ち合いでダメージが入りません。

### 対戦モード
- 待機所の「⚔ 対戦モード」看板（または `/trigger td.menu set 4`）を2人が押すと、空いているフィールド2つに1人ずつ入り、5秒のカウントダウンのあと **同じ瞬間に** スタートします（ルールは同じ）。
- 先にコアが落ちた方の負け（相手はその場で勝ち）。両方守り切ったら撃破数の多い方、同じならコアHPの多い方、それも同じなら引き分け。結果は全員のチャットに出ます。対戦中に片方が抜けると負け扱い。
- パネルの「対戦」でフィールドを2つ選んで始めることもできます（配信者どうしの対戦など）。対戦は同時に1組まで。配信者が割り当てられたフィールドは自動マッチングには使われません。

### ランキング
- ゲームが終わるたびに記録されます。ワールドの中（`td.rk` ベスト撃破数・`td.rt` 最長生存秒・`td.rw` 防衛成功回数・`td.rv` 対戦の勝ち数）と、アプリの `app\records.json`（全ゲームの結果とそのときのルール）の両方に残ります。
- 待機所の左のボードとパネルの「ランキング」は「いまのルール（制限時間・コアHP・関門HP・湧き間隔）」での記録の TOP。パネルでは全ルールの記録も見られます。だれもいないフィールドの結果はランキングに入りません。

- 関門の前に敵がいる間、関門の HP が減ります。0 になると関門が崩れ、プレイヤーは次の関門へ下がります。
- 全部の関門が崩れると最終防衛橋へ。敵がコアに着くとコアの HP が減り、0 で負け。制限時間（初期 10 分）を守り切れば勝ち。
- ギフトがなくても、敵は時間とともに増えながら自然に湧きます（間隔・数はパネルで変更）。

## ギフトの初期設定（パネルの「ギフト」タブで変更）
| コイン合計 | 敵（妨害） |
|---|---|
| 1〜 | ゾンビ |
| 5〜 | 俊足ゾンビ / スケルトン狙撃兵 |
| 10〜 | クリーパー（関門に大ダメージ） |
| 30〜 | 重装ゾンビ |
| 99〜 | ゾンビの大群（10体） |
| 299〜 | ボス・ラヴェジャー |
| 999〜 | 巨人タイタン |

助けるギフト（名前で指定）: ハートミー → 全員回復、アイスクリーム → 敵を凍結、香水 → 武器支給、ドーナツ → 関門を修理、
ハンドハート → 空爆、ギャラクシー → 全滅ボム。フォロー → ゾンビ、シェア → 俊足ゾンビ、サブスク → 武器支給、いいね1000ごと → 回復。

## パネル（複数フィールド対応）
- 上のカードで全フィールドの状態（残り時間・撃破・敵・関門・コア・いる人・配信者・TikTok の接続）が一目で見えます。カードをクリックする（または「操作するフィールド」で選ぶ）と、そのフィールドに対して ゲーム開始／停止／敵を消す／装備の配り直し／配信者をこのフィールドに入れる／このフィールドを作り直す が効きます。テストギフトとアクションの直接実行も、選んだフィールドだけに届きます。「全フィールドと待機所を作り直す」「待機所だけ作り直す」もあります。
- 接続設定: フィールドごとに「マイクラの名前」「TikTok の ID」（同時に複数接続）、個別の接続／切断。フィールド1 は前の「配信するアカウントの ID」です（前の config.json はそのまま読めます）。
- 対戦: フィールドA・B を選んで「対戦スタート」／「対戦を中止」、前回の結果。
- ランキング: TOP10（撃破数・生存時間・防衛成功・対戦の勝ち）と最近の結果。ログは「選んだフィールドだけ」にも絞れます。
- OBS: `http://127.0.0.1:8788/overlay?field=N` でフィールドごとのオーバーレイ（`?field` なしはフィールド1）。
- ゲーム・フィールドタブ: フィールドの数（1〜8）、フィールドどうしの間隔（初期 200。敵は 160 ブロック先まで人を追うので 170 以上推奨）。

## ディフェンダーの装備（装備セット）
パネルの「装備・武器」タブで、守る人が持つものを事前に決めておけます。
- **装備セット**: 銃（61種から最大9丁、弾は「マガジン数」×装弾数）・手りゅう弾・防具（頭/胴/脚/足の素材、ダメージ軽減 0〜4、壊れない）・そのほかのアイテム（ID・数・エンチャント `sharpness:5,unbreaking:3`・持ち物かオフハンド、最大12）・ずっと続く効果（最大6）。最大20セット、保存すると `config.json` に残ります。
- 最初から「標準」（前の初期装備と同じ）「スナイパー」「突撃（ショットガン）」「近接」「重装（機関銃）」が入っています。
- **フィールドごと**にどのセットを配るか選びます（配信者はフィールドに割り当てるので、配信者ごとに変えるのと同じ）。「ゲーム・テスト」タブの「このフィールドの装備セット」→「変える」／「変えて今すぐ配る」でも切り替えられます。
- 配るのはゲーム開始・ゲーム中の途中参加と入り直し・「装備を配り直す」のとき（持ち物はいったん空になり、効果も消えてから付け直し）。
- 保存のとき、サーバーが受け付けないアイテム（ID やエンチャントの間違い）があればパネルに出ます（そのアイテムだけ配られません）。
- しくみ: アプリがフィールドN のリストを storage `td:cfg lo.fN` に書き、データパックの `td:loadout_self` がプレイヤーの `td.fld` を見て配ります（`{id,count}` は give、`slot` 付きは `item replace`、`{eff,amp}` は無限の効果）。`td:cfg loadout` はフィールド1 と同じ（前のアプリ用の予備）。

## パネルで変えられること
- ギフト名・コインの段階ごとの割り当て、連打の回数、フォロー/シェア/サブスク/いいね/コメントコマンド
- ルール: 制限時間、コア HP、関門 HP、コアダメージ倍率、修理量、敵の上限、自然湧きの間隔・数・増え方、ボス/タイタンの上限
- フィールド: レーンの長さ・幅、関門の数、時刻、木の有無、場所（変えたら「フィールドを作り直す」）
- 敵MOB 7種の HP・速さ・大きさ・攻撃力・関門へのダメージ、ギフト1回で出す数
- 装備セット（下記）、弾の無限化、武器支給ギフトで届く銃とその弾の数
- クールダウン、キューの間隔、アイコンの大きさ、パネルのポート

## 作り直し
- MOD・シェーダーの取得: `python scripts\fetch_mods.py`（`mods.lock.json` を更新）
- データパック: `python datapack\build.py datapack\td_datapack.zip` → `server\world\datapacks` にコピーして `/reload`（フィールドの関数は `td:f1/…`〜`td:f8/…`。前の `td:start` `td:act/…` などはフィールド1 の意味でそのまま使えます）
- フィールド・待機所の地形: パネルの「全フィールドと待機所を作り直す」（API: `POST /api/game {"cmd":"build","field":"all"|"lobby"|N}`）
- 銃の一覧: `python scripts\gen_weapons.py`
- クライアント: `python scripts\build_client.py 1.0.1`（Prism インスタンスを更新し、`dist` に新しい .mrpack を作る）

## アプリの API（パネルが使っているもの）
`POST` には `X-TD-Panel: 1` ヘッダーが必要です。`field` を省くとフィールド1。
- `GET /api/state`（`fields[]` に各フィールドの状態）／ `GET /api/overlay?field=N` ／ `GET /api/leaderboard?scope=current|all`
- `POST /api/game {cmd:start|stop|clear|loadout|build, field}` ／ `POST /api/loadout {field, preset, give}`（フィールドの装備セットを変える、give で今すぐ配る） ／ `POST /api/test {field, action | gift,coins,repeat}` ／ `POST /api/clear {field}`
- `POST /api/versus {a,b}` ／ `{cancel:true}` ／ `POST /api/assign {field[, name]}` ／ `POST /api/tiktok {connect, field?}`

## メモ
- 1つのワールドなので、時刻・天気・ゲームルール（制限時間・HP・敵の強さなど）は全フィールド共通です。
- Complementary Reimagined は r5.9 以降が 26.2 のバイオーム（硫黄の洞窟）を参照して 26.1.2 では読み込めないため、r5.8 に固定しています。
- 敵は全員ヘルメット付きなので、夕焼けの時刻（12300）でも燃えません。
- Iris の「シェーダー再読み込み」は R キーが銃のリロードと重なるので、キー割り当てを外しています（シェーダーの切り替えは K、選択は O のまま）。
- アイコン表示には同梱のリソースパック（`td:px` フォント）が必要です。入っていない人には四角い記号に見えます。
